HTML

HTML (HyperText Markup Language) é a linguagem de marcação padrão para criar páginas web. Ela serve para estruturar o conteúdo das páginas na web.

CSS

CSS (Cascading Style Sheets) é uma linguagem de estilo usada para descrever a apresentação de um documento escrito em HTML ou XML. Ele permite controlar o layout, cores, fontes e outros aspectos visuais das páginas web.
